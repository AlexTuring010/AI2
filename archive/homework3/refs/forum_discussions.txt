Number of training samples
Updated 1 week ago by Emil Bantak
Καλησπερα σας,

Θα ηθελα να ρωτησω για τον αριθμο των samples που μπορουμε να χρησιμοποιησουμε απο το training set


Τρεχοντας τα μοντελα βλεπω για το 0.8B μοντελο για 100 samples θελει 8 λεπτα για να τελειωσει για το 2B μοντελο για 100 samples θελει 20 λεπτα και για το 4B θελει 50 λεπτα. Επειδη το training set εχει ~ 2900 samples δεν γινεται να τρεξουμε σε ενα notebook για αυτο training set και τα τρεια μοντελα μαζι και στην συνεχεια να τρεξουμε και το test set με ~ 800 samples για το καλυτερο μοντελο θα ξεπερασουμε τις 9 ωρες του session που εχει το kaggle


Στην εκφωνηση της εργασιας δεν βλεπω καπου να λεει οτι πρεπει να τρεξουμε και τα τρεια μοντελα με ολα τα samples απο το training set


Οποτε θελω να ρωτησω βασιζομενος σε ολα αυτα που εχω γραψει πιο πανω μπορουμε να τρεξουμε τα μοντελα σε λιγοτερα samples απο το training set πχ 300 samples θα ειναι αποδεκτο ? Τα samples αυτα θα ειναι φυσικα τα ιδια καθε φορα που τρεχουμε τον κωδικα για reproducibility reasons
