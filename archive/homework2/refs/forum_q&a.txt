Updated 2 weeks ago by Konstantinos Salmas
Hello,

If you do choose the T4 x2, mind you (I did not initially know :D) that it allows you for 2 parallel GPUs (hence the name), and while the quota is running you can actually speed up the process more by using something like:

if torch.cuda.device_count() > 1:
        model = nn.DataParallel(model)
model = model.to(DEVICE)
Which splits the batch into two GPUs. It does not drop the runtime in half (but it is a great boost).

Documentation: https://docs.pytorch.org/docs/stable/generated/torch.nn.DataParallel.html
